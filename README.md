
# Tendencias-de-Inteligencia-Artificial-Aplicada

## Actividad Formativa: Sistema de Recomendación con GitHub Copilot

### Proceso realizado
1. **Creación de cuenta y repositorio en GitHub:** Se configuró la cuenta personal (`LuisFCabrera`) y se creó el repositorio `Tendencias-de-Inteligencia-Artificial-Aplicada` inicializado con un archivo `README.md`.
2. **Configuración local en Visual Studio Code:** Se instaló Git para Windows, se vinculó la cuenta de GitHub en Visual Studio Code para habilitar GitHub Copilot y se clonó el repositorio en la carpeta local `D:\Proyectos github`.
3. **Generación del sistema de recomendación con Copilot:** Se creó el archivo `recommendation_system.py` y, mediante GitHub Copilot, se generó un modelo colaborativo de recomendación de productos utilizando `numpy`, `pandas` y `KNeighborsClassifier` de `scikit-learn`.
4. **Control de versiones:** Se registraron y subieron los archivos al repositorio remoto mediante los comandos `git add`, `git commit` y `git push`.
